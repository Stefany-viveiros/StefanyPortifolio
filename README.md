# StefanyPortifolio

Portfólio pessoal de Stefany Barboza — Engenharia da Computação, Análise e Desenvolvimento de Sistemas, desenvolvimento de software e IA.

## Stack
- React + Vite
- JavaScript (ES Modules)
- CSS responsivo, acessível e com suporte a redução de movimento
- Vitest + Testing Library

## Executar localmente
```bash
cd frontend
npm install
npm run dev
```

## Testes e build
```bash
npm test
npm run build
```

## Sobre o PinkBot
O PinkBot possui nesta versão uma experiência local e demonstrativa, com respostas estruturadas sobre o portfólio e navegação por seções. Ele **não** está conectado a um modelo de IA. A integração real com LLM será feita no backend em uma etapa posterior, mantendo chaves de API fora do navegador.
